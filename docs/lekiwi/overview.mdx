# 🔧 Lekiwi 底盘

**Lekiwi** 是一款全向移动的模块化机器人底盘平台，采用麦克纳姆轮布局，
提供灵活的全向运动能力与丰富的上装接口，是物流配送、巡检监控、服务机器人的理想移动基础。

## 📐 产品亮点

- **全向移动** — 麦克纳姆轮设计，支持前行、横移、斜行、原地旋转
- **高负载能力** — 强劲的轮毂电机，最大负载可达 50kg
- **模块化上装** — 标准快拆接口，快速切换不同应用载荷
- **SLAM 导航** — 集成激光雷达与 IMU，支持 Gmapping / Cartographer / SLAM Toolbox
- **长续航** — 大容量锂电池，标准续航 8 小时以上

## 📊 技术规格

| 参数           | 规格                                |
| -------------- | ----------------------------------- |
| 驱动方式       | 四轮独立驱动，麦克纳姆轮            |
| 最大负载       | 50kg                                |
| 最大速度       | 1.5 m/s                             |
| 越障能力       | ≤15mm 垂直 / ≤30° 斜坡              |
| 续航时间       | 8-12 小时（标配电池）               |
| 电池           | 24V / 20Ah 锂电池                   |
| 主控           | Raspberry Pi 5 / Jetson Orin NX     |
| 传感器         | 激光雷达 + IMU + 编码器 + 超声波     |
| 通信接口       | Wi-Fi 6 / 蓝牙 5.0 / USB 3.0 / CAN  |
| 自重           | ~18kg                               |
| 尺寸           | 600 × 500 × 280 mm                  |
| 软件平台       | ROS2 Humble + Nav2                  |

## 🎯 应用场景

- 📦 **物流配送** — 室内最后一公里配送，多机协同调度
- 🏢 **巡检监控** — 工厂、数据中心、仓储的自主巡检
- 🍽️ **餐饮服务** — 餐厅送餐、酒店物品递送
- 🔬 **科研平台** — 移动机器人算法研究与验证
- 🎓 **教育实训** — ROS2 导航教学实践平台
