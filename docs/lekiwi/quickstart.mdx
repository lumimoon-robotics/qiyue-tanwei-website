# ⚡ 快速开始

在 20 分钟内让你的 Lekiwi 底盘跑起来。

## 1. 环境要求

- **操作系统**: Ubuntu 22.04（推荐安装在主控上）
- **ROS2**: Humble Hawksbill
- **地面条件**: 平整室内地面

## 2. 硬件上电

```
         ┌──────────────────────┐
         │      Lekiwi 底盘     │
         │                      │
         │  [前]          [前]  │
         │  ┌──────────────┐    │
         │  │  激光雷达    │    │
         │  └──────────────┘    │
         │  ┌────┐    ┌────┐    │
         │  │ M1 │    │ M2 │    │ ← 麦克纳姆轮 ×4
         │  └────┘    └────┘    │
         │  ┌────┐    ┌────┐    │
         │  │ M3 │    │ M4 │    │
         │  └────┘    └────┘    │
         └──────────────────────┘
```

1. **安装电池** — 将电池组放入底盘电池仓，锁紧卡扣
2. **连接急停开关** — 确保急停开关处于释放状态（拉出）
3. **上电** — 按下电源键，等待系统启动（约 30 秒）
4. **连接 Wi-Fi** — 底盘默认创建 AP 热点 `Lekiwi-XXXX`，密码 `qiyue2024`

## 3. 遥控操作

```bash
# SSH 连接到底盘主控
ssh qiyue@lekiwi.local   # 默认密码: qiyue2024

# 启动底盘驱动
ros2 launch lekiwi_bringup base.launch.py

# 在本地电脑上启动键盘遥控（需要安装 teleop_twist_keyboard）
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```

键盘控制说明：
```
    i     — 前进
j   k   l — 左移/停止/右移
    ,     — 后退
u / o     — 逆时针/顺时针旋转
```

## 4. SLAM 建图

```bash
# 在底盘上启动 SLAM
ros2 launch lekiwi_slam online_async.launch.py slam_type:=cartographer

# 手动遥控底盘遍历需要建图的区域
# 在底盘上保存地图
ros2 run nav2_map_server map_saver_cli -f ~/maps/my_map
```

## 5. 自主导航

```bash
# 启动导航（使用刚才建立的地图）
ros2 launch lekiwi_nav bringup.launch.py map:=~/maps/my_map.yaml

# 在 Rviz 中设置目标点，底盘将自主规划并行驶
```

## 6. API 控制示例

```python
#!/usr/bin/env python3
""" 使用 Python API 控制 Lekiwi 底盘 """

from lekiwi_sdk import Chassis

# 连接底盘
bot = Chassis(host="lekiwi.local")

# 全向移动
bot.move(vx=0.3, vy=0.0, omega=0.0)   # 前进 0.3m/s
bot.move(vx=0.0, vy=0.3, omega=0.0)   # 右移 0.3m/s
bot.move(vx=0.0, vy=0.0, omega=0.5)   # 旋转 0.5 rad/s
bot.stop()

# 获取传感器数据
scan = bot.get_laser_scan()
print(f"前方障碍距离: {scan.min_distance}m")

# 导航到指定点
bot.navigate_to(x=2.0, y=1.5, yaw=0.0)
bot.wait_until_arrived()
print("✅ 已到达目标点")
```
