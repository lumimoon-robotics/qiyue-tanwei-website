# 👋 欢迎来到启月探微

**探微知著 · 启智未来** — 开源机器人技术与智能硬件平台。

## 📦 产品分类

### 🤖 [LeRobot 开源硬件](./lerobot/overview)

面向具身智能研究的全栈开源机器人硬件。

- 🦾 **SO-ARM101** — 6+1 自由度桌面机械臂
- 🔧 **Lekiwi** — 全向移动底盘平台
- 🤖 **Xlerobot** — AI 家务机器人

### 📷 [相机产品](./cameras/overview)

专为机器人感知设计的视觉模组。

- ⌚ **腕部相机** — 末端执行器集成视觉
- 📌 **固定相机** — 场景全局感知
- 👁️ **双相机** — 双目立体视觉方案

### ⚙️ [舵机产品](./servos/overview)

飞特 ST3215 系列高性能智能舵机。

- **C018 / C001 / C044 / C046** — ST3215 变体系列
- **SCS0009** — 微型智能舵机
