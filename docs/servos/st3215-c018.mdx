# ST3215 C018

ST3215 系列标准型智能总线舵机，平衡扭矩与速度，适用于通用机器人关节。

## 技术规格

| 参数 | 规格 |
|------|------|
| 型号 | ST3215 C018 |
| 扭矩 | 15 kg·cm (1.47 N·m) |
| 速度 | 0.15 s/60° |
| 精度 | 0.3° |
| 电压 | 6V - 12V |
| 通信 | RS485 总线 |
| 反馈 | 位置、速度、扭矩、温度 |
| 角度范围 | 0° - 360°（连续旋转） |
| 重量 | 85g |
| 尺寸 | 40×32×20 mm |

## 适用场景

- 轻量机械臂关节
- 云台控制
- 教育机器人

## 快速开始

```bash
pip install feetech-sdk
python -c "from feetech import Servo; s = Servo('/dev/ttyUSB0', 1); s.enable(); s.move(90)"
```
