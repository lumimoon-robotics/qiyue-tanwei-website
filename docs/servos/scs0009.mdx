# SCS0009

微型智能总线舵机，极致轻量与高速响应，适合空间严苛的精密应用。

## 技术规格

| 参数 | 规格 |
|------|------|
| 型号 | SCS0009 |
| 扭矩 | 5 kg·cm (0.49 N·m) |
| 速度 | 0.08 s/60° |
| 精度 | 0.1° |
| 电压 | 5V - 8.4V |
| 通信 | RS485 总线 |
| 反馈 | 位置、速度、扭矩、温度 |
| 重量 | 32g |
| 尺寸 | 26×20×12 mm |

## 适用场景

- 微型灵巧手指关节
- 云台微调
- 精密仪器控制
