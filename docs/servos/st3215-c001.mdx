# ST3215 C001

ST3215 系列高扭矩型，20kg·cm 输出，适合重载关节应用。

## 技术规格

| 参数 | 规格 |
|------|------|
| 型号 | ST3215 C001 |
| 扭矩 | 20 kg·cm (1.96 N·m) |
| 速度 | 0.12 s/60° |
| 精度 | 0.2° |
| 电压 | 6V - 12V |
| 通信 | RS485 总线 |
| 反馈 | 位置、速度、扭矩、温度 |
| 重量 | 95g |

## 适用场景

- 重载机械臂关节
- 足式机器人关节
- 工业夹爪
