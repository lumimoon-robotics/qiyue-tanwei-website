# ST3215 C046

ST3215 系列高精度型，±0.15° 控制精度，适合精密定位场景。

## 技术规格

| 参数 | 规格 |
|------|------|
| 型号 | ST3215 C046 |
| 扭矩 | 18 kg·cm (1.76 N·m) |
| 速度 | 0.13 s/60° |
| 精度 | 0.15° |
| 电压 | 6V - 12V |
| 通信 | RS485 总线 |
| 反馈 | 位置、速度、扭矩、温度 |
| 重量 | 90g |

## 适用场景

- 灵巧手关节
- 精密装配
- 实验室自动化
