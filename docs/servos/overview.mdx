# ⚙️ 舵机产品

基于飞特 ST3215 平台的系列智能总线舵机，覆盖不同扭矩、速度与控制精度需求。

## 产品线

| 型号 | 扭矩 | 速度 | 精度 | 定位 |
|------|------|------|------|------|
| [C018](./st3215-c018) | 15kg·cm | 0.15s/60° | 0.3° | 标准型，通用场景 |
| [C001](./st3215-c001) | 20kg·cm | 0.12s/60° | 0.2° | 高扭矩型 |
| [C044](./st3215-c044) | 10kg·cm | 0.10s/60° | 0.2° | 高速型 |
| [C046](./st3215-c046) | 18kg·cm | 0.13s/60° | 0.15° | 高精度型 |
| [SCS0009](./scs0009) | 5kg·cm | 0.08s/60° | 0.1° | 微型高速舵机 |

## 共同特性

- **总线控制** — RS485 多机通信，支持 254 个节点
- **反馈完备** — 位置、速度、扭矩、温度实时回传
- **ROS2 驱动** — 标准 `joint_state` + PID 参数调节
- **宽压供电** — 6V-12V，兼容各类机器人平台
