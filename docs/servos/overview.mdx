# ⚙️ 舵机产品

基于飞特 ST3215 平台的系列智能总线舵机，覆盖从标准型到高精度、从常规尺寸到微型的不同需求。
全系列支持 RS485 总线多机通信与完整状态反馈。

## 共同特性

### 🔌 总线控制
RS485 多机通信协议，单个总线最多支持 254 个舵机节点。简化布线，减少线缆杂乱。

### 📊 完整反馈
每个舵机实时回传位置、速度、扭矩、温度四项数据，支持闭环控制与状态监控。

### 🤖 ROS2 驱动
提供标准 `joint_state` 接口与 PID 参数调节面板，无缝集成 ROS2 机器人项目。

### ⚡ 宽压兼容
支持 6V-12V 供电范围，兼容 2S-3S 锂电池及各类机器人电源系统。

### 🛠️ 调试工具
配套上位机调试软件，支持参数读写、轨迹规划、多机同步等高级功能。
