# ⌚ 腕部相机

专为机械臂末端集成设计的超轻量相机模组，提供近距离高精度视觉引导。

## 技术规格

| 参数 | 规格 |
|------|------|
| 传感器 | 1/2.8" CMOS |
| 分辨率 | 1920×1080 @ 60fps |
| 视场角 | 90° (H) × 60° (V) |
| 重量 | 35g |
| 尺寸 | 38×28×22 mm |
| 接口 | USB 3.0 Type-C |
| 对焦 | 8cm ~ ∞ 自动对焦 |
| 软件 | ROS2 / OpenCV / Python SDK |

## 应用场景

- 🔧 精密装配视觉引导
- 📦 物体抓取定位
- 🧪 实验操作监控
- 🎓 机器视觉教学

## 快速开始

```bash
# 安装驱动
pip install qiyue-camera-sdk

# 启动 ROS2 节点
ros2 launch qiyue_camera wrist.launch.py
```
