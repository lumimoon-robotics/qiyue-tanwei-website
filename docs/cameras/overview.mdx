# 📷 相机产品

专为机器人感知场景设计的视觉模组，覆盖末端操作、全局感知与立体视觉三大需求。
所有相机提供 ROS2 标准接口与 Python/C++ SDK，即插即用。

---

## ⌚ 腕部相机

超轻量末端集成相机，用于灵巧操作视觉引导。

| 参数 | 规格 |
|------|------|
| 传感器 | 1/2.8" CMOS |
| 分辨率 | 1920×1080 @ 60fps |
| 视场角 | 90° × 60° |
| 重量 | 仅 35g |
| 对焦 | 8cm ~ ∞ 自动对焦 |
| 接口 | USB 3.0 Type-C |

**亮点**
- 仅重 35g，不影响机械臂末端负载
- 60fps 高帧率，适配动态抓取场景
- 自动对焦覆盖 8cm 近距离微距
- 标配 ROS2 `sensor_msgs` 驱动

---

## 📌 固定相机

高分辨率全局感知相机，适合工作区场景理解。

| 参数 | 规格 |
|------|------|
| 传感器 | 1/2.3" CMOS |
| 分辨率 | 2560×1440 @ 30fps |
| 视场角 | 120° × 80° |
| 重量 | 85g |
| 安装 | 1/4" 标准螺孔 + 磁吸底座 |
| 接口 | USB 3.0 / GigE |

**亮点**
- 2K 分辨率，清晰捕捉场景细节
- 120° 超广角，单相机覆盖大面积工作区
- 多种安装方式，灵活部署
- 支持 GigE 远距离传输

---

## 👁️ 双相机

双目立体视觉模组，提供实时深度图与点云。

| 参数 | 规格 |
|------|------|
| 传感器 | 2× 1/2.8" CMOS |
| 分辨率 | 2× 1920×1080 @ 30fps |
| 基线距离 | 65mm |
| 深度范围 | 0.3m ~ 10m |
| 重量 | 120g |
| 接口 | USB 3.0 Type-C |

**亮点**
- 实时深度估计，30fps 深度图输出
- 65mm 基线，类人眼双目布局
- 配套标定工具，一键完成双目校准
- 适用于 SLAM、3D 重建、深度引导抓取
