# 📷 相机产品

专为机器人感知场景设计的视觉模组，覆盖末端操作、全局感知与立体视觉三大需求。

## 产品线

| 产品 | 类型 | 分辨率 | 定位 |
|------|------|--------|------|
| [腕部相机](./wrist/overview) | 末端集成 | 1080P | 灵巧操作视觉引导 |
| [固定相机](./fixed/overview) | 场景感知 | 2K | 全局环境理解 |
| [双相机](./dual/overview) | 双目立体 | 1080P×2 | 深度估计与 SLAM |

## 设计特点

- **机器人专属** — 针对机械臂末端振动、运动模糊等场景优化
- **ROS2 原生** — 标准 `sensor_msgs` 接口，即插即用
- **紧凑轻量** — 最小仅重 35g，不影响末端负载
- **SDK 完备** — Python/C++ API，含标定、校准工具
