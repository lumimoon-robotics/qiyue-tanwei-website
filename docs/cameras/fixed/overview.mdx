# 📌 固定相机

高分辨率全局感知相机，安装于工作区上方或机器人外部，
提供广角场景理解与物体检测。

## 技术规格

| 参数 | 规格 |
|------|------|
| 传感器 | 1/2.3" CMOS |
| 分辨率 | 2560×1440 @ 30fps |
| 视场角 | 120° (H) × 80° (V) |
| 重量 | 85g |
| 尺寸 | 65×45×35 mm |
| 接口 | USB 3.0 / GigE |
| 安装 | 1/4" 标准螺孔 + 磁吸底座 |
| 软件 | ROS2 / OpenCV / Python SDK |

## 应用场景

- 🏠 场景全局感知
- 📸 物体检测与分类
- 🔍 工作区监控
- 🤖 机器人导航辅助

## 快速开始

```bash
pip install qiyue-camera-sdk
ros2 launch qiyue_camera fixed.launch.py
```
