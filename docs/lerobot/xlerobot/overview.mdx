# 🤖 Xlerobot 家务机器人

**Xlerobot** 是一款集成端侧 AI 推理、多模态感知与灵巧操作能力的家用服务机器人，
可自主学习并完成物品整理、桌面清洁、衣物折叠等日常家务任务。

## 📐 产品亮点

- **端侧 AI 推理** — 板载 NPU，毫秒级场景理解，无需云端
- **视觉-语言模型** — 自然语言指令理解，所见即所得
- **模仿学习** — 通过遥操作示教快速学习新技能
- **多模态融合** — 深度相机 + 触觉传感器 + 力矩感知
- **安全协作** — 碰撞检测、力矩限制，人机共融安全

## 📊 技术规格

| 参数           | 规格                                  |
| -------------- | ------------------------------------- |
| 自由度         | 双臂各 7 DoF + 腰部 2 DoF（可选）     |
| 末端执行器     | AmazingHand 灵巧手 / 二指夹爪（可换）  |
| 移动平台       | Lekiwi 全向底盘                       |
| 高度           | 1.45m（不含升降柱）                   |
| 自重           | ~45kg                                 |
| 有效载荷       | 单臂 3kg                              |
| 续航           | 6-8 小时                              |
| 计算平台       | Jetson Orin / 高通 RB6                 |
| 传感器         | 深度相机×2 / 触觉阵列 / IMU×2          |
| 通信           | Wi-Fi 6 / 蓝牙 5.0 / USB 3.0          |
| 软件平台       | ROS2 + PyTorch + 自研模仿学习框架      |

## 🎯 应用场景

- 🏠 **家庭服务** — 整理收纳、桌面清洁、衣物折叠、物品取送
- 🏥 **医疗辅助** — 物品递送、康复训练辅助
- 🛒 **商业服务** — 零售货架补货、仓储理货
- 🔬 **具身智能研究** — 模仿学习、多模态感知、任务规划
