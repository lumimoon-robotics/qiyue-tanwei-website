# 🔧 Lekiwi 全向移动底盘

**Lekiwi** 是一款全向移动的模块化机器人底盘平台，采用麦克纳姆轮布局，
提供灵活的全向运动能力与丰富的上装接口。

![Lekiwi](/img/lekiwi.png)

## 技术规格

| 参数 | 规格 |
|------|------|
| 驱动方式 | 四轮独立麦克纳姆轮 |
| 最大负载 | 50kg |
| 最大速度 | 1.5 m/s |
| 续航 | 8-12 小时 |
| 主控 | Raspberry Pi 5 / Jetson Orin NX |
| 传感器 | 激光雷达 + IMU + 超声波 |
| 自重 | ~18kg |
| 尺寸 | 600 × 500 × 280 mm |
| 软件 | ROS2 Humble + Nav2 |

## 亮点

- **全向移动** — 前行、横移、斜行、原地旋转
- **SLAM 导航** — Cartographer / SLAM Toolbox 自主建图
- **模块化上装** — 标准快拆接口，一底多用
- **长续航** — 8-12 小时标配电池

## 应用场景

- 📦 物流配送 — 室内最后一公里
- 🏢 巡检监控 — 工厂、数据中心自主巡检
- 🍽️ 餐饮服务 — 餐厅送餐、酒店递送
- 🔬 科研平台 — 移动机器人算法验证
