# 3D 打印指南

> **预计时间：约 34 小时**

## 打印参数

| 参数 | 推荐值 | 备注 |
|------|--------|------|
| 材料 | PLA / PLA+ | 通用即可 |
| 喷嘴直径 | 0.2 mm | |
| 层高 | 0.2 mm | |
| 填充密度 | 15% | |
| 打印速度 | 150 mm/s | |
| 支撑 | 按需开启 | 仅标记了「需要支撑」的零件 |

## 打印步骤

1. 将 STL 文件导入切片软件（Bambu Studio、PrusaSlicer 等）
2. 对标记为「需要支撑」的零件启用支撑
3. 使用推荐参数切片，上传 G-code 到打印机

### 后处理
- 从打印平台取下打印件
- 拆除支撑结构
- 检查螺丝孔是否通畅（如需可用钻头清理）

## 没有 3D 打印机？

可以选择在线 3D 打印服务，或选购市面上已有的套件。
