# ✋ AmazingHand 灵巧手

**AmazingHand** 是一款模拟人手解剖结构的五指机器人灵巧手，
集成高密度触觉传感器阵列与力反馈控制系统，可实现精细的抓取与操作任务。

![AmazingHand](/img/amazinghand.png)

## 技术规格

| 参数 | 规格 |
|------|------|
| 手指数量 | 5 指 |
| 自由度 | 16（拇指4 + 食指3 + 中指3 + 无名指3 + 小指3） |
| 关节类型 | 微型无刷电机 + 谐波/行星减速器 |
| 指尖力范围 | 0-15N（可调） |
| 触觉分辨率 | 24 点/指尖（共 120 个触觉单元） |
| 力控精度 | ±0.1N |
| 抓取物体范围 | φ1mm - φ120mm |
| 自重 | ~1.1kg |
| 通信接口 | CAN / RS485 / USB |
| 供电 | 24V DC |

## 亮点

- **仿人手结构** — 5 指 16 自由度，模拟人手运动学
- **触觉感知** — 指尖集成 24 点触觉阵列，感知接触力分布
- **力反馈控制** — 实时力矩反馈，精准力控精度可达 0.1N
- **即插即用** — 标准机械接口，兼容 SO-ARM101、UR、Kinova 等主流臂
- **开源设计** — CAD 文件、驱动电路、控制算法全开源

## 应用场景

- 🧪 科研实验 — 灵巧操作、触觉感知、强化学习研究
- 🏭 精密装配 — 电子元器件装配、精密仪器操作
- 🏥 医疗辅助 — 康复训练、手术辅助工具操作
- 🦾 假肢研发 — 智能假肢控制算法验证
