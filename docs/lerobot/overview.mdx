# 🤖 LeRobot 开源硬件

**LeRobot** 是启月探微面向具身智能研究推出的全栈开源机器人硬件系列，
包含桌面机械臂、移动底盘与家用服务机器人三大产品线。

## 产品线

| 产品 | 类型 | 定位 |
|------|------|------|
| [SO-ARM101](./so-arm101/overview) | 桌面机械臂 | 教育科研、轻量自动化 |
| [Lekiwi](./lekiwi/overview) | 移动底盘 | 物流配送、巡检导航 |
| [Xlerobot](./xlerobot/overview) | 服务机器人 | 家庭服务、具身智能研究 |

## 设计理念

- **全栈开源** — CAD / PCB / 固件 / SDK 全面开放
- **模块化** — 各产品间接口标准化，可自由组合
- **教育友好** — 从入门到精通，完整教程体系
- **AI 原生** — 深度集成 ROS2、PyTorch、模仿学习框架
