# 🤖 LeRobot 开源硬件

**LeRobot** 是启月探微面向具身智能研究推出的全栈开源机器人硬件系列，
包含桌面机械臂、移动底盘与家用服务机器人三大产品线。所有硬件采用 Apache 2.0 协议开源，
提供完整的 CAD 设计文件、BOM 清单、装配指南与软件 SDK。

---

## 🦾 SO-ARM101 桌面机械臂

面向教育与科研的轻量级开源机械臂。

![SO-ARM101](/img/so-arm101.png)

| 参数 | 规格 |
|------|------|
| 自由度 | 6 + 1（夹爪） |
| 有效载荷 | ≥ 500g |
| 工作半径 | ≥ 350mm |
| 重复定位精度 | ±0.5mm |
| 自重 | ~3.5kg |
| 软件平台 | ROS2 Humble / Python 3.10+ |

**亮点**
- 全开源 CAD 设计文件与 BOM 清单
- ROS2 原生支持，提供 URDF 模型与 MoveIt 配置
- Python SDK，15 分钟快速上手
- 支持位置/速度/力矩三种控制模式

---

## 🔧 Lekiwi 全向移动底盘

模块化机器人移动平台，一底多用。

![Lekiwi](/img/lekiwi.png)

| 参数 | 规格 |
|------|------|
| 驱动方式 | 四轮独立麦克纳姆轮 |
| 最大负载 | 50kg |
| 最大速度 | 1.5 m/s |
| 续航 | 8-12 小时 |
| 主控 | Raspberry Pi 5 / Jetson Orin NX |
| 软件 | ROS2 Humble + Nav2 |

**亮点**
- 麦克纳姆轮全向移动，支持原地旋转
- SLAM 自主导航，兼容 Cartographer / SLAM Toolbox
- 模块化上装快拆接口
- 集成激光雷达 + IMU + 超声波传感器

---

## 🤖 Xlerobot 家务机器人

AI 驱动的双臂服务机器人。

![Xlerobot](/img/xlerobot.png)

| 参数 | 规格 |
|------|------|
| 自由度 | 双臂各 7 DoF + 腰部 2 DoF（可选） |
| 移动平台 | Lekiwi 全向底盘 |
| 高度 | 1.45m |
| 自重 | ~45kg |
| 续航 | 6-8 小时 |
| 计算平台 | Jetson Orin / 高通 RB6 |

**亮点**
- 端侧 AI 推理，毫秒级场景理解
- 视觉-语言模型驱动自然语言交互
- 模仿学习框架，遥操作示教快速部署新技能
- 碰撞检测 + 力矩限制，安全人机协作
