## 概述

当本地没有足够的 NVIDIA GPU 时，可以使用云 GPU 平台进行模型训练。本文介绍主流云 GPU 平台的选择和配置方法。
## 支持的 GPU 架构要求

> ⚠️ 重要限制：LeRobot 部分训练依赖不支持 V100（Volta 架构）

> 必须使用 Ampere 架构及以上：RTX 30xx、RTX 40xx、A100、H100、RTX A6000 等

| GPU 型号 | 架构 | 支持 LeRobot | 显存 |
| --- | --- | --- | --- |
| V100 | Volta | ❌ 不支持 | 32GB |
| RTX 3080 | Ampere | ✅ 支持 | 10GB |
| RTX 3090/4090 | Ampere/Ada | ✅ 支持 | 24GB |
| RTX A6000 | Ampere | ✅ 推荐 | 48GB |
| A100 | Ampere | ✅ 推荐 | 40/80GB |
| H100 | Hopper | ✅ 推荐 | 80GB |

## 主流云 GPU 平台

### NVIDIA Brev（推荐，国际）

- 特点：NVIDIA 官方云平台，稳定性高，支持 GPU 直接访问
- 推荐 GPU：RTX A6000（48GB）或 A100
- 官网：[brev.dev](https://brev.dev)
```text
# 在 Brev 上创建环境后，标准配置流程
git clone https://github.com/huggingface/lerobot.git
cd lerobot
pip install -e ".[feetech]"
# 训练
lerobot-train \
    --policy.type=act \
    --dataset.repo_id=YOUR_HF_USERNAME/my_dataset
```
### AutoDL（国内推荐）

- 特点：国内主流，价格较低，速度快（无需翻墙）
- 推荐 GPU：RTX 4090、A100
- 官网：[autodl.com](https://www.autodl.com)
```text
# AutoDL 配置流程（在 JupyterLab 终端中操作）
# 推荐使用 PyTorch 2.x 镜像
conda create -n lerobot python=3.12
conda activate lerobot
git clone https://github.com/huggingface/lerobot.git
cd lerobot
pip install -e ".[feetech]"
```
### 阿里云 / 腾讯云 / 华为云

各大云厂商均提供 GPU 实例，按需选择：

| 云厂商 | 推荐实例类型 | 特点 |
| --- | --- | --- |
| 阿里云 | gn6i（T4）/ gn7i（A10） | 国内速度快 |
| 腾讯云 | GN10X（V100 ❌）/ GN7 （A10 ✅） | 注意避开 V100 |
| 华为云 | GPU 加速型 | 支持国产 GPU |

## 标准云端训练流程

### Step 1：准备数据集

在本地采集好数据集并上传到 HuggingFace：
```text
# 本地采集并上传
lerobot-record ... --dataset.push_to_hub=true
```
### Step 2：配置云端环境

```text
# SSH 连接到云服务器后
conda create -n lerobot python=3.12
conda activate lerobot
git clone https://github.com/huggingface/lerobot.git
cd lerobot
pip install -e ".[feetech]"
# 登录 HuggingFace（下载数据集用）
huggingface-cli login
```
### Step 3：启动训练

```text
# 训练命令（数据集自动从 HuggingFace 下载）
lerobot-train \
    --policy.type=act \
    --dataset.repo_id=YOUR_HF_USERNAME/my_dataset \
    --training.num_epochs=200 \
    --training.batch_size=64 \
    --training.use_wandb=true \
    --output_dir=outputs/train/act_my_task
```
### Step 4：下载模型

训练完成后将模型下载到本地或上传 HuggingFace：
```text
# 上传到 HuggingFace（在云端运行）
huggingface-cli upload YOUR_HF_USERNAME/act_my_task \
    outputs/train/act_my_task/checkpoints/last/pretrained_model/
# 或通过 scp 下载到本地
scp -r user@server:~/lerobot/outputs/train/act_my_task/checkpoints/last/ 
./local_model/
```
## PyTorch + CUDA 版本对应关系

不同云平台的 CUDA 版本可能不同，注意确认兼容性：

| PyTorch 版本 | CUDA 版本 | Python 版本 | 说明 |
| --- | --- | --- | --- |
| 2.3.x | 12.1 | 3.10-3.12 | 主流推荐 |
| 2.2.x | 12.1 | 3.10-3.12 | 稳定版 |
| 2.1.x | 11.8 | 3.10-3.11 | 旧版兼容 |

```text
# 验证 GPU 和 PyTorch 配置
python -c "
import torch
print(f'PyTorch: {torch.__version__}')
print(f'CUDA: {torch.version.cuda}')
print(f'GPU 可用: {torch.cuda.is_available()}')
print(f'GPU 型号: {torch.cuda.get_device_name(0)}')
print(f'显存: {torch.cuda.get_device_properties(0).total_memory / 1e9:.1f} GB')
"
```
## 多 GPU 训练

如果云服务器有多张 GPU，可以利用多 GPU 并行训练：
```text
# 使用 torchrun 启动多 GPU 训练
torchrun --nproc_per_node=4 \
    $(which lerobot-train) \
    --policy.type=act \
    --dataset.repo_id=YOUR_HF_USERNAME/my_dataset \
    --training.batch_size=128   # 4 GPU 可以用更大的 batch
```
