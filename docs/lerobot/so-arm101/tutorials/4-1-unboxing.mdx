## 4.1.1 概述

收到套件后，请按本文清单逐一核对零件，确保无遗漏或损坏，再开始组装。
## 4.1.2 开箱检查流程

在干净平坦的桌面上开箱

2. 取出所有零件，按类别分组摆放
3. 对照下方清单逐一清点
4. 检查舵机外壳是否完好，连接线是否齐全
5. 如发现缺件或损坏，立即联系供应商

## 4.1.4 常见问题

Q：收到的舵机有些会轻微转动，正常吗？A：正常。STS3215 舵机在未上电时可以手动转动，这是正常现象。

Q：USB 线有两种，怎么区分数据线和充电线？A：用数据线连接电脑后，系统应能识别到串口设备（如 /dev/ttyACM0 ）；纯充电线无法被识别。

Q：3D 打印件有些孔偏小，怎么处理？A：可用小钻头（M2 用 2mm，M3 用 3mm）轻轻手钻扩孔，不要强行压入螺丝。
