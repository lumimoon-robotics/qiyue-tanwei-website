### 电源适配器

- 要求：5V 输出，功率建议 ≥ 2A
### 桌面固定夹

- 普通 C/F 型夹，五金店或网购均可
- 建议最大开口 ≥ 5cm，以适应不同桌面厚度
## 2.3.4 摄像头选购建议

数据采集和模型推理均需要摄像头：

| 相机类型 | 推荐型号 | 用途 |
| --- | --- | --- |
| 通用 USB 摄像头 | 罗技 C920/C930e | 顶置/侧置视角 |
| 小型 UVC 模组 | 32×32mm USB 模组 | 腕部相机 |
| 深度相机 | Intel RealSense D405 | 3D感知（进阶） |
| 深度相机 | Intel RealSense D435 | 广角3D感知 |

入门建议：两个普通 USB 摄像头即可（一顶置+一腕部），无需购买深度相机，也可以只要一个腕部相机，是最划算的入门方案。启月有购买的套件链接，包括对应的安装支架。后续也会把支架的stl上传，降低大家的DIY成本。

## 2.3.5 购买清单速查

### 最小化入门配置

1. 成品双臂套装（或按BOM自行采购）
2. USB摄像头 * 1
3. 有 NVIDIA GPU 的电脑（训练用）或 Mac/普通电脑（仅遥操作）
### 完整研究配置

除了以上，还可以增加

1. USB 摄像头 × 2-3（顶置 + 腕部）
2. NVIDIA GPU（RTX 3080 及以上，训练推荐）
3. Intel RealSense 深度相机（可选）
4. 触觉传感器（可选，研究用）
