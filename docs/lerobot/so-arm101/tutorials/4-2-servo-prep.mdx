## 4.2.1 概述

在组装机械臂之前，需要先完成舵机的基础认识、控制板接线和中位校准。这是组装中最关键的一步，舵机配置正确与否直接影响后续校准和遥操作效果。

| ![图](/img/tutorial/so-arm101/4-2-servo-prep-p1-1.png) | ![图](/img/tutorial/so-arm101/4-2-servo-prep-p1-2.png) |

### 关键特性

| 参数 | 值 |
| --- | --- |
| 型号 | STS3215（飞特舵机） |
| 工作电压 | 主动臂：7.4V（C001/C044/C046）；从动臂较大负载：12V（C018）；从动臂正常负载：7.4V（C001） |
| 通信方式 | 单线串行总线 |
| 默认 ID | 1（出厂设置） |
| 默认波特率 | 1,000,000 bps（1Mbps） |
| 角度范围 | 0°–360°（位置模式） |

### 舵机连接线说明

STS3215 使用 3 针连接线：
```text
红线  ──  VCC（电源正极，由控制板供电：主动臂 7.4V / 从动臂 12V）
黑线  ──  GND（电源负极）
白线  ──  DATA（串行数据线，半双工）
```

>注意：舵机电源由控制板统一提供，主动臂接 5V 适配器（控制板输出 7.4V 给舵机），从动臂接 12V适配器。不可将 USB 5V 直接接到舵机！

## 4.2.4 控制板接线

### 控制板与电源连接

不同品牌控制板的供电接口设计不同，请按实际型号操作，我这里采用的是微雪控制板
### 微雪（Waveshare）控制板

| 机械臂 | 接口 | 输入电压 |
| --- | --- | --- |
| 主动臂（Leader） | DC 电源口 | 5V 适配器 |
| 从动臂（Follower） | DC 电源口 | 若从动臂是正常负载（ST3215-C001舵机），则接5V适配器；若从动臂是较大负载（ST3215-C018舵机），则接12V适配器 |

### 上电后舵机指示灯判断

接通电源后，通过舵机红色指示灯判断电源是否正常：

| 指示灯状态 | 含义 | 处理方式 |
| --- | --- | --- |
| 🔴 长亮红灯 | 电源电压正常，舵机就绪 | 正常，可继续操作 |
| 🔴 红灯闪烁 | 电源电压异常（过高或过低） | 立即断电，检查适配器规格 |

重要：如出现红灯闪烁，务必立即断电。常见原因是主从臂适配器接错。确认后再重新通电。

### 控制板跳线设置

使用总线舵机控制板时，必须确认跳线帽设置正确（以 Waveshare 为例，其他型号请参考对应说明书）：

![图](/img/tutorial/so-arm101/4-2-servo-prep-p4-11.png)

常见错误：跳线帽未放到 B 通道会导致电脑无法识别串口。
### 舵机与控制板连接

![图](/img/tutorial/so-arm101/4-2-servo-prep-p5-12.png)

1. 连接5V或12V电源适配器
2. 电源接线端子（不常用）
3. 通过USB连接电脑
4. 跳线帽（默认处于B，USB连接模式）
5. 连接舵机（任意一个均可）
6. UART串口（不常用，需要跳线帽处于A才能使用）每次配置舵机 ID 时，只连接一个舵机，设置完 ID 后再接入下一个。
