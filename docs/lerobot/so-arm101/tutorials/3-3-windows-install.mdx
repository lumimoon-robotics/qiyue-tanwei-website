### 3.3.1 概述

Windows 用户可以通过 WSL2（Windows Subsystem for Linux）运行 LeRobot，本文介绍 WSL2 的配置方式以及 Windows 原生安装的注意事项。
## 3.3.2 WSL2简介

### WSL2（Windows Subsystem for Linux）

由于 LeRobot 对 Linux 支持最完善，强烈推荐 Windows 用户使用 WSL2 运行 LeRobot，而不是直接在 Windows 原生环境安装。
### WSL2 vs 原生 Windows 对比

| 方面 | WSL2 | 原生 Windows |
| --- | --- | --- |
| 兼容性 | 优秀，接近原生 Linux | 部分依赖不支持 |
| 串口访问 | 需要额外配置 | 原生支持 |
| GPU 训练 | 支持（通过 WSLg） | 支持 |
| 推荐度 | ★★★★★ | ★★★ |

## 3.3.3 WSL2环境下安装步骤

### 第一步：安装 WSL2

### 开启 WSL2

以管理员身份打开 PowerShell，执行：
```text
# 安装 WSL2 并默认安装 Ubuntu
wsl --install
# 重启电脑后，Ubuntu 会自动初始化
# 设置用户名和密码后即可使用
```
### 安装 Ubuntu 22.04（推荐）

```text
# 安装指定版本
wsl --install -d Ubuntu-22.04
# 查看已安装的发行版
wsl --list --verbose
```
### 第二步：在 WSL2 中安装 LeRobot

打开 Ubuntu 终端，按照 [3.2 Ubuntu 环境安装](./3-2-ubuntu-install) 的步骤操作：
```text
# 安装 conda
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh
source ~/.bashrc
# 创建环境
conda create -n lerobot python=3.12
conda activate lerobot
# 安装 LeRobot
git clone https://github.com/huggingface/lerobot.git
cd lerobot
pip install -e ".[feetech]"
```
### 第三步：WSL2 串口访问配置

WSL2 默认无法直接访问 Windows 的 USB 设备，需要通过 usbipd 工具将 USB 设备转发到WSL2。
### 安装 usbipd-win

在 Windows 中（PowerShell 管理员模式）：
```text
# 使用 winget 安装
winget install --interactive --exact dorssel.usbipd-win
# 或下载安装包：
# https://github.com/dorssel/usbipd-win/releases
```
### 将串口设备转发到 WSL2

每次连接控制板时执行以下步骤：
```text
# 1. 查看所有 USB 设备
usbipd list
# 找到控制板对应的 BUSID（如 1-3）
# 2. 绑定设备（只需执行一次）
usbipd bind --busid 1-3
# 3. 连接到 WSL2（每次插拔后需重新执行）
usbipd attach --wsl --busid 1-3
```

在 WSL2 中验证：
```text
# 应显示 /dev/ttyACM0 或 /dev/ttyUSB0
ls /dev/ttyACM* /dev/ttyUSB*
# 设置串口权限
sudo chmod 666 /dev/ttyACM0
```
### 常见端口名称

在 WSL2 中，Windows 串口对应的设备名称可能为：

- /dev/ttyACM0 （常见）
- /dev/ttyUSB0 （CH340 类控制板）
- /dev/ttyS* （COM 口映射，不常用）
### 第四步：WSL2 GPU 支持（训练用）

WSL2 支持通过 CUDA 使用 NVIDIA GPU：
```text
# Windows 端：安装最新 NVIDIA 驱动（≥527.41）
# 下载地址：https://www.nvidia.com/drivers
# WSL2 中不需要单独安装 NVIDIA 驱动
# 只需安装 CUDA Toolkit
# 在 WSL2 中安装 CUDA Toolkit（仅 toolkit，不含驱动）
# 参考 Ubuntu 安装文档中的 CUDA 安装步骤
# 验证
python -c "import torch; print(torch.cuda.is_available())"
```
## 3.3.4 原生 Windows 安装（不推荐但可行）

如果不使用 WSL2，可以尝试原生 Windows 安装：
### 安装步骤

```text
# 安装 Python 3.12（lerobot 要求 >=3.12）
# 下载：https://www.python.org/downloads/
# 创建虚拟环境
python -m venv lerobot_env
.\lerobot_env\Scripts\activate
# 克隆并安装 LeRobot
git clone https://github.com/huggingface/lerobot.git
cd lerobot
pip install -e ".[feetech]"
```
### 串口配置

Windows 原生使用 COM 端口（如 COM3），需要在命令中指定：
```text
lerobot-find-port
# Windows 下输出类似：COM3, COM4
lerobot-setup-motors \
    --robot.type=so101_follower \
    --robot.port=COM3
```
### CH340 驱动安装

如果 Windows 无法识别控制板，安装 CH340/CH341 驱动：

- 下载地址：WCH 官网
## 3.3.5 WSL 相关常见问题

Q：WSL2 中看不到 USB 设备？A：

1. 确认 usbipd attach 已执行
2. 检查 usbipd-win 版本是否最新
3. 以管理员身份运行 PowerShell Q：每次重启后需要重新执行 usbipd attach？A：可以创建 PowerShell 脚本或任务计划自动执行：
```text
# 保存为 attach_robot.ps1
usbipd attach --wsl --busid 1-3
```

Q：WSL2 内存占用过高？A：在 %USERPROFILE%\.wslconfig 中限制内存：
```text
[wsl2]
memory=8GB
processors=4
```
