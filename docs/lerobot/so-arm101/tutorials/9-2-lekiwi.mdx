### 概述

LeKiwi 是由 Hugging Face 和合作伙伴开发的低成本全向移动底盘，可以与 SO-101 机械臂组合使用，构成完整的移动操作机器人。
### 底盘特性

| 特性 | 规格 |
| --- | --- |
| 移动方式 | 全向移动（Holonomic） |
| 驱动轮 | 3 个麦克纳姆轮 / 全向轮 |
| 通信方式 | Wi-Fi 无线 / USB 有线 |
| 供电 | 锂电池（可选规格） |
| 计算单元 | 树莓派 5 / Jetson（可选） |

### 全向移动原理

```text
麦克纳姆轮布局：
     前
  [L]   [R]
     后
  [B]
三轮全向布局可实现：
- 前后移动
- 左右平移
- 原地旋转
- 任意方向组合运动
```

### 所需零件

| 零件 | 数量 |
| --- | --- |
| 全向轮组件（含电机） | 3 套 |
| 底盘主体（3D打印件） | 1 套 |
| 电机驱动板 | 1 块 |
| 树莓派 5 / 计算模块 | 1 个 |
| 锂电池 + BMS | 1 套 |
| USB Hub | 1 个 |

### 组装步骤

1. 组装底盘主体结构件（3D打印件）
2. 安装三个全向轮组件
3. 连接电机驱动板
4. 安装计算模块（树莓派 5）
5. 安装电池和 BMS
6. 布线整理

- 主芯片上贴最薄的那片导热贴
- 散热器通过两个扣位固定到主板上，风扇朝上

# 用 Raspberry Pi Imager 将镜像写入 MicroSD 卡

步骤 5：接无线遥控手柄（可选）

- 先装上电池测试无线遥控手柄功能

### 安装 LeRobot（树莓派端）

```text
# 树莓派上安装 LeRobot
git clone https://github.com/huggingface/lerobot.git
cd lerobot
pip install -e ".[lekiwi]"   # 安装 LeKiwi 相关依赖
```
### LeKiwi 遥操作

```text
# 电脑端（发送控制指令）
# 将 192.168.x.x 替换为树莓派实际 IP
lerobot-teleoperate \
    --robot.type=lekiwi \
    --robot.remote_ip=192.168.x.x \
    --teleop.type=gamepad
# 或用键盘控制
lerobot-teleoperate \
    --robot.type=lekiwi \
    --robot.remote_ip=192.168.x.x \
    --teleop.type=keyboard
```
### 与 SO-101 联合使用

### 配置说明

LeKiwi + SO-101 联合配置时，所有设备通过树莓派（或 Jetson）集中管理：
```text
树莓派 / Jetson：
├── /dev/ttyACM0 → 从动臂控制板
├── /dev/ttyACM1 → （可选：第二条机械臂）
├── /dev/video0  → 摄像头1
└── Wi-Fi         → 与上位机通信
```
### 联合遥操作命令

```text
# 同时控制移动底盘 + 机械臂（XLeRobot 模式）
lerobot-teleoperate \
    --robot.type=xlerobot \
    --robot.lekiwi_ip=192.168.x.x \
    --robot.arm.port=/dev/ttyACM0 \
    --teleop.type=bimanual_leader
```
### 常见问题

Q：LeKiwi 底盘移动不直，有偏转？A：检查三个轮子的安装角度，确保每个轮子方向符合设计图纸要求。

Q：Wi-Fi 延迟高，控制有卡顿？A：优先使用 5GHz Wi-Fi；考虑使用有线 USB 连接减少延迟。

Q：电池续航多久？A：取决于电池容量和负载，通常 1-3 小时。
