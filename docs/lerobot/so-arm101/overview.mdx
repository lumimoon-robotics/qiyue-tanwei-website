# 🦾 SO-ARM101 机械臂

**SO-ARM101** 是一款面向教育与科研场景的轻量级开源机械臂，具备 6+1 自由度，
提供完整的开源设计文件、软件 SDK 与教学资源。

## 📐 产品亮点

- **6+1 自由度** — 灵活的姿态控制与末端操作能力
- **全开源设计** — CAD 文件、PCB 设计、BOM 清单全部公开
- **ROS2 原生支持** — 无缝接入 ROS2 生态，提供完整的 URDF 模型与 MoveIt 配置
- **Python SDK** — 简洁易用的 Python API，降低开发门槛
- **丰富的教学资源** — 从零基础到高级应用，完善的教程体系

## 📊 技术规格

| 参数         | 规格                              |
| ------------ | --------------------------------- |
| 自由度       | 6 + 1（夹爪）                     |
| 有效载荷     | ≥ 500g                            |
| 工作半径     | ≥ 350mm                           |
| 重复定位精度 | ±0.5mm                            |
| 自重         | ~3.5kg                            |
| 通信接口     | USB / UART / Wi-Fi（可选）         |
| 供电         | 12V DC / 24V DC                   |
| 关节类型     | 智能总线舵机 / 无刷电机（可选）    |
| 控制方式     | 位置控制 / 速度控制 / 力矩控制     |
| 软件平台     | ROS2 Humble / Python 3.10+        |

## 🎯 应用场景

- 🎓 **高校教学** — 机器人学、运动学、控制理论课程实验平台
- 🔬 **科研实验** — 强化学习、模仿学习、灵巧操作研究
- 🏭 **轻量级自动化** — 分拣、装配、视觉检测
- 🧑‍💻 **创客项目** — 开源社区二次开发与创意应用
