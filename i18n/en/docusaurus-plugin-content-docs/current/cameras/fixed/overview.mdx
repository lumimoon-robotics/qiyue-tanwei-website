# 📌 Fixed Camera

High-resolution global perception camera, mounted above workspaces for wide-angle scene understanding.

## Specifications

| Parameter | Value |
|-----------|-------|
| Sensor | 1/2.3" CMOS |
| Resolution | 2560×1440 @ 30fps |
| FOV | 120° (H) × 80° (V) |
| Weight | 85g |
| Interface | USB 3.0 / GigE |
| Mount | 1/4" standard + magnetic base |
| Software | ROS2 / OpenCV / Python SDK |

## Quick Start

```bash
pip install qiyue-camera-sdk
ros2 launch qiyue_camera fixed.launch.py
```
