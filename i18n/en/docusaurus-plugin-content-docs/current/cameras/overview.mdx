# 📷 Camera Products

Vision modules purpose-built for robotic perception — covering end-effector guidance, global scene awareness, and stereo depth. All cameras feature ROS2 standard interfaces and Python/C++ SDKs, plug and play.

---

## ⌚ Wrist Camera

Ultra-lightweight end-effector camera for dexterous manipulation guidance.

| Parameter | Specification |
|-----------|---------------|
| Sensor | 1/2.8" CMOS |
| Resolution | 1920×1080 @ 60fps |
| FOV | 90° × 60° |
| Weight | 35g only |
| Focus | 8cm ~ ∞ autofocus |
| Interface | USB 3.0 Type-C |

**Highlights**
- Only 35g — no payload compromise
- 60fps for dynamic grasping scenarios
- 8cm close-range autofocus
- ROS2 `sensor_msgs` driver included

---

## 📌 Fixed Camera

High-resolution global perception camera for workspace scene understanding.

| Parameter | Specification |
|-----------|---------------|
| Sensor | 1/2.3" CMOS |
| Resolution | 2560×1440 @ 30fps |
| FOV | 120° × 80° |
| Weight | 85g |
| Mount | 1/4" standard + magnetic base |
| Interface | USB 3.0 / GigE |

**Highlights**
- 2K resolution captures fine scene details
- 120° ultra-wide FOV covers large work areas
- Multiple mounting options for flexible deployment
- GigE support for long-distance transmission

## 👁️ Dual Camera

Stereo vision module providing real-time depth maps and point clouds.

| Parameter | Specification |
|-----------|---------------|
| Sensors | 2× 1/2.8" CMOS |
| Resolution | 2× 1920×1080 @ 30fps |
| Baseline | 65mm |
| Depth Range | 0.3m ~ 10m |
| Weight | 120g |
| Interface | USB 3.0 Type-C |

**Highlights**
- Real-time depth estimation at 30fps
- 65mm baseline, human-like stereo layout
- Calibration toolkit for one-click stereo calibration
- Ideal for SLAM, 3D reconstruction, and depth-guided grasping
