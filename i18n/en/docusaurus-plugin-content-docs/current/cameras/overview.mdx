# 📷 Camera Products

Vision modules purpose-built for robotic perception, covering end-effector guidance, global awareness, and stereo depth.

## Product Lines

| Product | Type | Resolution | Use Case |
|---------|------|------------|----------|
| [Wrist Camera](./wrist/overview) | End-Effector | 1080P | Dexterous manipulation guidance |
| [Fixed Camera](./fixed/overview) | Scene Perception | 2K | Global environment understanding |
| [Dual Camera](./dual/overview) | Stereo Vision | 1080P×2 | Depth estimation & SLAM |

## Key Features

- **Robot-Optimized** — Designed for arm vibrations and motion blur
- **ROS2-Native** — Standard `sensor_msgs` interface, plug-and-play
- **Ultra-Compact** — As light as 35g, no payload compromise
- **Complete SDK** — Python/C++ APIs with calibration tools
