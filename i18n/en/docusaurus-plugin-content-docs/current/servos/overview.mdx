## Common Features

### 🔌 Bus Control
RS485 multi-drop protocol, up to 254 servos on a single bus. Simplified wiring, reduced cable clutter.

### 📊 Full Feedback
Each servo streams real-time position, velocity, torque, and temperature data for closed-loop control and monitoring.

### 🤖 ROS2 Driver
Standard `joint_state` interface with PID tuning panel. Seamless integration with ROS2 robotics projects.

### ⚡ Wide Voltage
6V-12V input range, compatible with 2S-3S LiPo batteries and various robot power systems.

### 🛠️ Debugging Tools
Companion software for parameter read/write, trajectory planning, and multi-servo synchronization.
