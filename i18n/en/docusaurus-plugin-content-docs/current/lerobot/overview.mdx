# 🤖 LeRobot Open Hardware

**LeRobot** is Qiyue Robotics' full-stack open-source hardware series for embodied AI research, featuring a desktop robotic arm, mobile chassis, home service robot, and dexterous hand. All hardware is open-sourced under Apache 2.0, with complete CAD design files, BOM, assembly guides, and software SDKs.

---

## 🦾 SO-ARM101 Desktop Robotic Arm

A lightweight open-source robotic arm for education and research.

![SO-ARM101](/img/so-arm101.png)

| Parameter | Specification |
|-----------|---------------|
| DOF | 6 + 1 (gripper) |
| Payload | ≥ 500g |
| Reach | ≥ 350mm |
| Repeatability | ±0.5mm |
| Weight | ~3.5kg |
| Software | ROS2 Humble / Python 3.10+ |

**Highlights**
- Fully open-source CAD files and BOM
- Native ROS2 support with URDF + MoveIt
- Python SDK, up and running in 15 minutes
- Position/velocity/torque control modes

## 🔧 Lekiwi Omnidirectional Chassis

A modular mobile robot platform — one base, endless applications.

![Lekiwi](/img/lekiwi.png)

| Parameter | Specification |
|-----------|---------------|
| Drive | 4× independent Mecanum wheels |
| Max Payload | 50kg |
| Max Speed | 1.5 m/s |
| Battery Life | 8-12 hours |
| Controller | Raspberry Pi 5 / Jetson Orin NX |
| Software | ROS2 Humble + Nav2 |

**Highlights**
- Omnidirectional movement with zero-radius turning
- SLAM autonomous navigation (Cartographer / SLAM Toolbox)
- Modular quick-swap top plate interface
- Integrated LiDAR + IMU + ultrasonic sensors

AI-powered dual-arm service robot.

![Xlerobot](/img/xlerobot.png)

|-----------|---------------|

| Height | 1.45m |
| Weight | ~45kg |

**Highlights**

## ✋ AmazingHand Dexterous Hand

Five-finger tactile dexterous hand for precision grasping and manipulation.

![AmazingHand](/img/amazinghand.png)

| Parameter | Value |
|-----------|-------|
| DOF | 16 (thumb 4 + index 3 + middle 3 + ring 3 + pinky 3) |
| Fingertip Force | 0-15N |
| Tactile Resolution | 24 pts/fingertip (120 total) |
| Force Precision | ±0.1N |
| Weight | ~1.1kg |
| Interface | CAN / RS485 / USB |

**Highlights**
- 5-finger 16-DOF human-like kinematics
- 120 tactile units with real-time force feedback
- Compatible with SO-ARM101, UR, Kinova and more
- Fully open-source CAD + drivers + control algorithms
