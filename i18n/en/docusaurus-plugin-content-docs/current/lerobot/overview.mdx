# 🤖 LeRobot Open Hardware

**LeRobot** is Qiyue Robotics' full-stack open-source hardware series for embodied AI research, featuring a desktop robotic arm, mobile chassis, and home service robot.

## Product Lines

| Product | Type | Positioning |
|---------|------|-------------|
| [SO-ARM101](./so-arm101/overview) | Desktop Arm | Education, light automation |
| [Lekiwi](./lekiwi/overview) | Mobile Chassis | Logistics, inspection |
| [Xlerobot](./xlerobot/overview) | Service Robot | Home service, embodied AI |

## Design Philosophy

- **Full Open Source** — CAD, PCB, firmware, SDK all under Apache 2.0
- **Modular** — Standardized interfaces between products
- **Education-Friendly** — Complete tutorials from beginner to advanced
- **AI-Native** — Deep ROS2, PyTorch, and imitation learning integration
