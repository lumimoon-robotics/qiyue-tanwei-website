# 🤖 Xlerobot Home Robot

An AI-powered home service robot integrating on-device inference, multimodal perception, and dexterous manipulation.

## Highlights

- **On-Device AI** — NPU-powered real-time scene understanding
- **Vision-Language Model** — Natural language instruction following
- **Imitation Learning** — Learn new skills via teleoperation demos
- **Safe Collaboration** — Collision detection + torque limiting

## Specifications

| Parameter | Value |
|-----------|-------|
| DOF | Dual 7-DOF arms + 2-DOF waist (optional) |
| End-Effector | AmazingHand / 2-finger gripper (swap) |
| Mobile Base | Lekiwi omnidirectional chassis |
| Height | 1.45m |
| Weight | ~45kg |
| Payload | 3kg per arm |
| Battery | 6-8 hours |
| Compute | Jetson Orin / Qualcomm RB6 |
| Sensors | Depth camera ×2 / Tactile array / IMU ×2 |
| Software | ROS2 + PyTorch + IL framework |

## Applications

- 🏠 Home organization, cleaning, laundry folding
- 🏥 Medical assistance & rehab
- 🛒 Retail & warehouse
- 🔬 Embodied AI research
