# 🔧 Lekiwi Chassis

An omnidirectional mobile robot chassis with Mecanum wheels, designed as a versatile base platform.

## Highlights

- **Omnidirectional** — Forward, strafe, diagonal, zero-radius turn
- **50kg Payload** — Powerful hub motors
- **Modular Top Plate** — Quick-swap payloads
- **SLAM Navigation** — LiDAR + IMU, Gmapping/Cartographer/Toolbox
- **8h+ Battery Life** — Large capacity Li-ion

## Specifications

| Parameter | Value |
|-----------|-------|
| Drive | 4× independent Mecanum wheel |
| Max Payload | 50kg |
| Max Speed | 1.5 m/s |
| Battery | 24V / 20Ah Li-ion |
| Main Controller | Raspberry Pi 5 / Jetson Orin NX |
| Sensors | LiDAR + IMU + Encoders + Ultrasonic |
| Software | ROS2 Humble + Nav2 |

## Applications

- 📦 Last-mile delivery
- 🏢 Facility inspection
- 🍽️ Food & hotel service
- 🔬 Mobile robotics research
