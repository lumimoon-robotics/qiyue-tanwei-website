# 🔧 Lekiwi Omnidirectional Chassis

**Lekiwi** is an omnidirectional modular robot chassis with Mecanum wheels,
offering flexible omnidirectional movement and a rich top-plate interface.

![Lekiwi](/img/lekiwi.png)

## Specifications

| Parameter | Value |
|-----------|-------|
| Drive | 4× independent Mecanum wheels |
| Max Payload | 50kg |
| Max Speed | 1.5 m/s |
| Battery Life | 8-12 hours |
| Controller | Raspberry Pi 5 / Jetson Orin NX |
| Sensors | LiDAR + IMU + Ultrasonic |
| Weight | ~18kg |
| Dimensions | 600 × 500 × 280 mm |
| Software | ROS2 Humble + Nav2 |

## Highlights

- **Omnidirectional** — Forward, strafe, diagonal, zero-radius turn
- **SLAM Navigation** — Cartographer / SLAM Toolbox
- **Modular Top Plate** — Standard quick-swap interface
- **Long Battery Life** — 8-12 hours standard

## Applications

- 📦 Last-mile delivery
- 🏢 Facility inspection
- 🍽️ Food & hotel service
- 🔬 Mobile robotics research
