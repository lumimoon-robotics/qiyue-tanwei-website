# 3D Printing Guide

> **Estimated time: ~34 hours**

All STL files are located in the `Code/3DPrintMeshes/` directory. They can be printed using generic PLA filament on a consumer-grade FDM printer, and have been tested and verified on the Bambu Lab P1S.

## Print Parameters

| Parameter | Recommended | Notes |
|------|--------|------|
| Material | PLA / PLA+ | Generic is fine |
| Nozzle Diameter | 0.2 mm | |
| Layer Height | 0.2 mm | |
| Infill Density | 15% | |
| Print Speed | 150 mm/s | |
| Supports | Enable as needed | Only for parts marked "Requires supports" |

## Printing Steps

1. Import STL files into your slicer (Bambu Studio, PrusaSlicer, etc.)
2. Enable supports for parts marked "Requires supports"
3. Slice with recommended parameters and upload G-code to the printer

### Post-Processing
- Remove printed parts from the build plate
- Remove support structures
- Check that screw holes are clear (use a drill bit to clean if needed)

## No 3D Printer?

Consider using an online 3D printing service, or purchase an off-the-shelf kit if available.
