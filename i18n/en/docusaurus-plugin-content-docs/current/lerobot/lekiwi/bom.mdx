# Bill of Materials (BOM)

Complete parts list required to build the LeKiwi mobile manipulator. **The 12V version is recommended**, providing more powerful performance at a modest budget increase.

## Version Selection

LeKiwi offers two power supply options:

| Version | Target Audience | Features |
|------|---------|------|
| **🔵 12V Version** (Recommended) | All users | Lithium battery powered, high torque, can carry heavier items |
| **🟡 Wired Version** | Fixed workstation R&D | Connects to laptop via USB-C cable, no battery or Raspberry Pi needed |
