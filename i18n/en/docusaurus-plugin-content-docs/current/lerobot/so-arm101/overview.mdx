# 🦾 SO-ARM101 Robotic Arm

A lightweight open-source robotic arm with 6+1 DOF for education and research.

## Highlights

- **6+1 DOF** — Flexible pose control and end-effector operation
- **Fully Open Source** — CAD, PCB, BOM all publicly available
- **ROS2-Native** — URDF model + MoveIt configuration included
- **Python SDK** — Clean API for rapid development
- **Educational Resources** — Complete tutorials from beginner to advanced

## Specifications

| Parameter | Value |
|-----------|-------|
| DOF | 6 + 1 (gripper) |
| Payload | ≥ 500g |
| Reach | ≥ 350mm |
| Repeatability | ±0.5mm |
| Weight | ~3.5kg |
| Interface | USB / UART / Wi-Fi (optional) |
| Power | 12V DC / 24V DC |
| Software | ROS2 Humble / Python 3.10+ |

## Applications

- 🎓 University robotics courses
- 🔬 Reinforcement learning & imitation learning research
- 🏭 Light automation tasks
- 🧑‍💻 Maker & community projects
