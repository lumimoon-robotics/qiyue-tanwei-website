# ✋ AmazingHand Dexterous Hand

**AmazingHand** is a five-finger robotic dexterous hand that mimics human hand anatomy,
integrating high-density tactile sensor arrays and force feedback control for fine grasping and manipulation.

![AmazingHand](/img/amazinghand.png)

## Specifications

| Parameter | Value |
|-----------|-------|
| Fingers | 5 |
| DOF | 16 (thumb 4 + index 3 + middle 3 + ring 3 + pinky 3) |
| Joint Type | Micro brushless motor + harmonic/planetary reducer |
| Fingertip Force | 0-15N (adjustable) |
| Tactile Resolution | 24 points/fingertip (120 tactile units total) |
| Force Precision | ±0.1N |
| Grasp Range | φ1mm - φ120mm |
| Weight | ~1.1kg |
| Interface | CAN / RS485 / USB |
| Power | 24V DC |

## Highlights

- **Human-like Structure** — 5 fingers, 16 DOF, mimicking human hand kinematics
- **Tactile Sensing** — 24-point tactile array per fingertip for contact force distribution
- **Force Feedback** — Real-time torque feedback, precision up to 0.1N
- **Plug & Play** — Standard mechanical interface, compatible with SO-ARM101, UR, Kinova, etc.
- **Open Source** — CAD files, driver circuits, control algorithms all open source

## Applications

- 🧪 Research — Dexterous manipulation, tactile sensing, reinforcement learning
- 🏭 Precision Assembly — Electronics assembly, precision instrument operation
- 🏥 Medical Assistance — Rehabilitation training, surgical tool handling
- 🦾 Prosthetics R&D — Smart prosthetic control algorithm validation
