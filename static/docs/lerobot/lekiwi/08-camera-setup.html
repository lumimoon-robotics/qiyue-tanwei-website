摄像头设置 ​

LeKiwi 支持两种摄像头方案，对应不同的 3D 打印支架。

支持的摄像头 ​

型号类型支架文件
Arducam 5MP 广角USB 摄像头模块base_camera_mount.stl + wrist_camera_mount.stl
标准 USB 网络摄像头USB 网络摄像头webcam_mount/ 系列

方案 1：Arducam 5MP 广角摄像头 ​

适用于 Arducam 5MP。

摄像头在 Linux 上通常映射为 /dev/video0 和 /dev/video2。

方案 2：USB 网络摄像头 ​

适用于 USB 网络摄像头。

验证摄像头 ​

在树莓派上检查 ​

bash
# 列出所有摄像头设备
ls /dev/video*

# 使用 ffmpeg 测试
ffmpeg -f v4l2 -list_formats all -i /dev/video0

在 LeRobot 中测试 ​

bash
conda activate lerobot
python -c "
import cv2
cap = cv2.VideoCapture(0)
ret, frame = cap.read()
if ret:
    print(f'摄像头分辨率: {frame.shape[1]}x{frame.shape[0]}')
else:
    print('无法读取摄像头')
cap.release()
"

摄像头配置参数 ​

参数默认值说明
camera_index/dev/video0 或数字索引摄像头设备路径
fps30帧率
width640图像宽度
height480图像高度
rotation0旋转角度（0/90/180/270）

故障排查 ​

问题解决方案
摄像头无画面运行 ls /dev/video* 检查设备
画面黑屏尝试 /dev/video0～/dev/video3
权限不足 (Linux)sudo chmod 666 /dev/video*
画面倒置设置 rotation=180
